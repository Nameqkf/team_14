## 프로젝트 소개

📊 유튜브 영상 의도에 따른 시청자 반응 분석 대시보드

이 프로젝트는 유튜브 영상의 기획 및 연출 의도(긍정/부정 프레이밍)가 시청자 댓글의 동조/반박 반응에 미치는 영향을 비교 분석하는 Streamlit 기반 인터랙티브 대시보드입니다.


📌 주요 분석 주제 (총 8개)

라면 논쟁: 진라면 vs 신라면 시장 입지와 가성비 담론

한중 청년 인식: 국가 간 혐오 vs 온정적 상호작용 프레이밍

쉬었음 청년 담론: 구직 단념에 대한 개인적 태도 비판 vs 사회적 구조 한계

아일릿 신곡 반응: 차트 반응 및 중독성 호평 vs 기획력 및 완성도 혹평

이무진 표절 의혹: 멜로디 유사성 표절 주장 vs 화성 코드 진행 분석을 통한 반박

영화 《호프(HOPE)》: 나홍진 감독의 미장센/몰입감 호평 vs 개연성/난해함 혹평

영화 《미키 17》: 봉준호 감독의 철학적 위로 호평 vs 상업적 단순화 혹평

영화 《군체》: 연상호 감독의 군집사고 풍자 호평 vs 전개/디테일 완성도 혹평

## 앱 실행 화면



🖥 주요 화면 기능

Page 1: 댓글 긍정/부정 비율 분석

각 영상의 연출 의도에 대한 시청자 반응(동조 vs 반박) 비율을 도넛 차트(Plotly)로 시각화

Page 2: 영상별 대표 댓글 분석

영상 의도에 부합하는 동조 댓글과 반박 댓글을 카드 뷰 형태로 최대 6개씩 제시

200자 초과 댓글은 자동 말줄임표(...) 처리

## 실행 방법

1. 의존성 라이브러리 설치

터미널에서 프로젝트 루트 디렉토리로 이동한 뒤 설치합니다:

python3 -m pip install -r requirements.txt


2. Streamlit 대시보드 구동

아래 명령어를 실행하여 웹 브라우저에서 대시보드를 확인합니다:

python3 -m streamlit run app.py
